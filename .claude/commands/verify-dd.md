Review all design docs in /docs for implementation readiness.

## Instructions

For each doc:

1) Create a testable checklist with pass/fail criteria,
2) Identify any gaps or ambiguities,
3) Cross-reference against our deployment requirements and implementation consistency. Use sub-tasks to parallelize across docs. Don't stop until every checklist item is specific enough to verify in under 5 minutes.

## Report

Write one report file to `plans/verify-dd-{YYYY-MM-DD}.md` — invoking this command is the explicit request for a separate review file, and it goes outside `docs/`, which holds none (`docs/README.md`). Group it by doc: the checklist, the gaps, and prioritized action items for improving that doc. Leave the docs themselves unedited; applying the action items is a separate step.
